## F1 · 每日练习主线（产品脊柱）

```mermaid
flowchart TD
    A([学生打开 App]) --> B["今日任务卡<br/>15 词 · 预计 12 分钟"]
    B -->|"开始练习"| C["练习屏 · 逐题作答"]
    C -->|"答完当日量"| D["收尾小结<br/>对错分布 + 明日预告"]
    D --> E([结束 · 次日回访])
    C -.答错·支线.-> F["错词入强化队列"]
    F --> G["明日任务自动混入错词"]
    G --> B
```

## F2 · 错题强化回路

```mermaid
flowchart TD
    A([错词连续 3 天答错]) --> B["标记为顽固词"]
    B --> C["进入周末强化包"]
    C -->|"连续 2 次答对"| D([移出强化队列])
    C -.仍错.-> B
```

## 流程教给我们的事

1. "今日任务卡"是脊柱屏：三条流都回到它。
2. 错词回路完全后台化，学生不需要管理复习计划。
