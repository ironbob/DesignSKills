# 阶段 8 评审判据卡：交互说明 + 可点原型 + Crit

评审对象：`08-交互说明.md` + `08-prototype.html` + `08-findings.md`。先读 `review-conventions.md`。
决策类别：**豁免类**——crit 的修复路径可自动复核；🟡 豁免是否成立必停人工。本卡评审的是"crit 三件产物本身是否合格"，**不重做 crit**（crit 由独立会话产出，此评审是其产物的完整性审计）。
注：手机（mobile_app）项目工作台的结构/manifest 悬空/五类覆盖/可达性/section 同步由 L1 gate（PROTOTYPE 查）机械验，评审不重复数数；此处验"结构对了但行为/语义不对"的部分，并抽查 manifest 与真实行为一致。桌面/Web 项目按 R8-16 判原型形态。
