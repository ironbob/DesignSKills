# 阶段 5 评审判据卡：视觉方向

评审对象：`05-style-tiles/`（tile-a/b/c.html + index.html）。上游锚点：设计前提（人像/气质线索）。先读 `review-conventions.md`。
决策类别：**生成质量=事实类可评；挑方向=品味类必停人工**。评审对"气质可辨"只做结构性判定（是否同路微调），不判哪个更美。

## 判据

| # | 判据（离散，三值判定） | 级别 |
|---|---|---|
| R5-1 | 恰好三个方向（a/b/c），文件齐 | 🔴 |
| R5-2 | 每方向五件齐：色板 / 字型样张 / 组件小样 / 核心内容手感 / 一句话气质+适配风险 | 🔴 |
| R5-3 | 色板含领域语义色，且为"符号+文字+色"呈现（不只靠色区分） | 🔴 |
| R5-4 | 字型样张三级字号实样 + 领域专用族（如等宽记谱） | 🟡 |
| R5-5 | 组件小样与核心内容手感用**真实数据**（与 04 灰框同源数据更佳） | 🔴 |
| R5-6 | 核心内容手感用阶段 4 已选结构呈现（换方向不换结构骨架） | 🔴 |
| R5-7 | 跨方向不变项一致：声明的不变骨架（如"核心区恒最亮底""一屏一强调"）三方向全部遵守 | 🔴 |
| R5-8 | 三方向是真实分叉（明度策略/密度/质感至少一项系统性不同），非同一路三档微调 | 🔴 |
| R5-9 | index.html 对照表齐：一句话 / 最契合 / 主要风险 三列 | 🟡 |
| R5-10 | 适配性/风险描述具体（指向人像或场景，非"适合大多数用户"套话） | 🟡 |

## 常见命中示例

- R5-7 命中：`tile-b 核心内容区用了 90% 灰底，违反"核心区恒为最亮底"不变项`
- R5-8 命中：`三方向仅强调色 hue 不同，明度/密度/质感策略一致（同路微调）`
- R5-10 命中：`风险栏写"可能不够美观"，无具体人像/场景指向`

## 放行

🔴=0 且覆盖完整 → 停人工挑方向（品味类）；拍板记台账（含语义色终值），选中方向初始化 tokens 草稿。
