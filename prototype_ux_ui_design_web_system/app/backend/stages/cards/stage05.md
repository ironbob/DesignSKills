# 阶段 5：视觉方向（任务卡）

**style tiles，不是整屏**：配色/字型/质感小样，×3 方向给人挑。视觉是全流程第一次"审美决策"，用小样决策成本最低。

输入：设计前提（人像/气质线索/参考产品）；当前项目画布（tile 小样宽度跟随项目画布）。

## 产出（`05-style-tiles/`）

- `tile-a.html` / `tile-b.html` / `tile-c.html`：每套五件——
  1. **色板**：底/面/界线/墨/弱墨/强调 + **领域语义色**（带符号+文字，不只靠色）；
  2. **字型样张**：标题族/正文族/领域专用族（如等宽记号）+ 三级字号实样；
  3. **组件小样**：主按钮/次按钮/列表行（真实数据）；
  4. **核心内容手感**：本领域核心内容的最小样（阶段 4 已定的结构穿上本方向的颜色）；
  5. **一句话气质 + 适配性/风险**（"最契合谁、主要风险是什么"，如实写）。
- `index.html`：三方向对照表（一句话/最契合/主要风险）。

**先定不变项再画方向**：跨方向恒定的骨架先写进 index（如"核心内容区恒为最亮底""语义=符号+方向词+色三元组""一屏一强调"）——换方向不换语义骨架。

**rapid 模式**：只产**一个**默认视觉方向（单 tile + index；L1 gate 要求 ≥1 tile），必须写明从人像、需求、阶段 4 结构与既定不变项的推导；默认方向与推导记台账（source=rapid_default）。五件齐/语义三元组/真实数据/不变项等其余要求不变。

## 完成标志（L1 gate）

tile-a/b/c + index 齐；index 对照表逐一提及三个 tile；HTML 过负面文案扫描。气质真实可辨（不是同路微调）由 L2 评审判。

## 工具化要点

- 决策类型=gallery：界面按 tile 文件生成方向选择卡，可指定混搭（"A 为基底但核心区纯白"），拍板记台账（含语义色终值）。品味类：任何模式必停人工。
