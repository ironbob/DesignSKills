## 预研证据·存储性能：五项指标全面改善 {#s5}

<p class="lead">真机同口径实测：不是某项赢，是全面赢——三项提速 61–65%，内存峰值 -30%，库体积 -17%。</p>

预研在 iPhone 13 真机（iOS 17.4，Release 构建）上用同一数据集对比 Core Data 与 GRDB：5 万条单词记录加 120 万条学习记录，覆盖冷启动、批量写入、SRS 调度查询、内存与存储体积五个维度。
