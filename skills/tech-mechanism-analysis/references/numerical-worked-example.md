# 数值操作工作示例

工作示例用于证明分析与原代码一致，不是装饰性公式。

## 必备内容

- `operation`：运算名称。
- `sample_data`：能触发核心行为、分支或边界的具体输入。
- `computation_steps`：至少两个可核步骤，包含输入归一化、分支、核心运算或结果映射。
- `result`：明确结果和单位。
- `faithfulness_note`：说明如何与代码对应，以及是否实际运行或等价翻译。
- `evidence`：被演算代码的位置。

## 忠实性

保留所有会影响结果的行为：

- 单位和精度
- clamp、量化、取整和溢出
- 查表与分支
- 随机种子
- 状态依赖

需要翻译 C++、shader 或其他实现来求值时，记录 `code_translation`。翻译只能等价求值，不能替换为教科书近似公式。

## 模式差异

- Lite：只演算理解机制所必需的核心操作。
- Full：每个 `numerical=true` 阶段至少有一个示例。

如果原机制没有核心数值操作，明确说明，不要制造示例。
