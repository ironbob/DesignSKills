# 阶段 8：交互说明 + 可点原型 + Crit（任务卡）

## 目的

三件事：把状态语义定成**矩阵契约**、把主流程做成**可点原型**、对全量屏做**独立 crit**。审计与生成分离——crit 不携带生成会话的记忆。

## 产出与模板

**1. `08-交互说明.md`：**

- **核心屏模式×状态矩阵**（最复杂屏必做，其他屏状态清单）：

| 状态＼模式 | 模式 A | 模式 B |
|---|---|---|
| 进入准备 | … | … |
| 进行 | …（不适用态写"—（不适用）"+原因） | … |
| 异常中断（含阈值变体行） | … | … |
| 结束/收尾 | … | … |
| 正交标志（如录音中/无信号） | … | … |

- **转场标注表**：迁移 / 转场 / 时长缓动（进沉浸屏=底部上推；屏内状态=交叉淡入；反馈类=快 80ms；拍点同步类=120ms linear）；
- **未决 U-x**：发现的需求层歧义（PRD 没定死的语义），记录倾向方案，编码按倾向实现留切换。

**2. `08-prototype.html`**：主流程（产品脊柱那条）可点原型——单文件、固定画布、JS 状态机切换视图、右上角**流程定位条**（随时显示走到哪步）。覆盖：起点屏→…→核心屏全部状态→出口。

**3. `08-findings.md`**（crit，十维度逐屏过）：

| # | 维度 | 看 | 级别 |
|---|---|---|---|
| 1 | 单一焦点 | 一眼看出干什么、下一步点哪；主键最强且唯一 | 🔴 |
| 2 | 层级清晰 | 视觉权重 ≤3 档；无争宠区域 | 🔴 |
| 3 | 模式兑现 | 渲染兑现布局承诺（列表真主从？向导真分步？） | 🔴 |
| 4 | 文案纪律 | 全部对回内容清单；按钮动宾；真实数据 | 🔴 |
| 5 | 密度留白 | 呼吸感一致；无孤儿元素 | 🟡 |
| 6 | 对齐 | 共线者真共线；栅格一致 | 🟡 |
| 7 | 跨页一致 | 壳/节奏/组件与相邻页一致 | 🟡 |
| 8 | 状态完备 | 矩阵每格有实现；异常态语义正确 | 🟡 |
| 9 | 视口 | 降级策略落实；无横向滚动 | 🟡 |
| 10 | 微文案 | 引导弱化呈现；无自解释文字 | 🟢 |

finding 格式：`[Fx]（维度）位置（文件+区块）＋证据（引用内容）＋处置`。**每维度必有结论**（finding/过/不适用），沉默即违规。🔴 必修；🟡 处置=修复/豁免记录/进规格；未决挂 U-x。修复独立做，修完复审该条。

## 完成标志

🔴 清零；🟡 全处置；每维度有结论；可点原型走通主流程。

## 人工决策点

审 crit 处置（豁免是否成立）；U-x 的倾向方案确认。

## 工具化要点（网页工具映射）

- AI 任务：矩阵起草 / 原型组装 / **crit 独立会话**（只喂产物不喂生成上下文——对抗审计的独立性在工具里天然成立，因为每次调用本来就无记忆）。
- 界面：矩阵=可编辑表格；原型=iframe 运行；findings=审批清单（修复/豁免/转未决三按钮）。
- gate：🔴 未清零阻塞定稿（任务状态机里硬编码）；维度结论完整性检查。
