# 阶段 8：交互说明 + 可点原型 + Crit（任务卡）

## 目的

三件事：把状态语义定成**矩阵契约**、把主流程做成**可点原型**、对全量屏做**独立 crit**。审计与生成分离——crit 不携带生成会话的记忆。

阶段 7 交付的是单屏状态帧；本阶段把它们整合成**唯一的 `08-prototype.html`**——mobile 项目即原型工作台，不再平铺静态页。

## 产出与模板

- **核心屏模式×状态矩阵**（最复杂屏必做，其他屏状态清单）：

| 状态＼模式 | 模式 A | 模式 B |
|---|---|---|
| 进入准备 | … | … |
| 进行 | …（不适用态写"—（不适用）"+原因） | … |

| 结束/收尾 | … | … |
| 正交标志（如录音中/无信号） | … | … |

- **转场标注表**：迁移 / 转场 / 时长缓动（进沉浸屏=底部上推；屏内状态=交叉淡入；反馈类=快 80ms；拍点同步类=120ms linear）；
- **主流程 ↔ manifest 对照**：每条主流程（起点→…→出口）逐段列出 interaction manifest 路由 id，声明五类覆盖（main/success/cancel/error/recover 各至少一条）；
- **未决 U-x**：发现的需求层歧义（PRD 没定死的语义），记录倾向方案，编码按倾向实现留切换。

**2. `08-prototype.html`（唯一最终原型，按 tokens 目标端二选一）：**

- **mobile → 原型工作台**（结构/类名/manifest 格式契约见 `html-conventions.md` §8）：
  - 左 `.workbench-sidebar`（≈280px）：项目名、版本/日期、流程摘要；按模块分组页面列表（编号、页面名、简短状态），当前页高亮；点击任意页面项，右侧手机立即切到对应页面/状态；
  - 右主舞台：居中视觉完整手机机身；内部 `.device-frame` 严格=tokens.canvas（如 390×844），不拉伸、不换成桌面页面、内容内部滚动；手机下方 `.device-caption` 显示当前页面说明、当前状态、可执行交互提示（从 manifest 当前节点推导）；「重置流程」等调试控制可选，放外壳，**不得替代手机内真实控件**；
  - **interaction manifest**：内嵌 JSON 声明全部 screen/state/路由；页面列表、手机内交互、说明面板**共享同一状态机/路由表**——禁止静态平铺、禁止点击后无变化；
  - **主流程每一步由手机内真实控件触发**；侧栏只是测试与浏览入口，不得冒充产品交互，不得把工作台控件渗进手机产品页面；
  - 覆盖五类路径：起点、核心任务、成功出口、取消/返回、一个异常或校验失败状态、恢复/重试路径；
  - 双击可开、无网络、无框架依赖：内联 CSS/JS，禁止外部 CDN；输入、Tab、筛选、保存、弹层确认等控件必须改变可见状态（仅视觉按钮无行为=断链）。
- **desktop/web → 单文件可点原型**：`.frame` 锁目标画布 + 右上角流程定位条（沿用原形态）。

## 完成标志

1. **L1 四查全绿**：`check_artifacts.py 08-prototype.html --canvas-width <W> --canvas-height <H> --platform <mobile|desktop|web>`（platform 跟随 tokens 目标端）——TAG/CANVAS/COPY 之外，mobile 加验 PROTOTYPE：工作台结构（侧栏/手机画布锁定/说明面板）、manifest 无悬空目标、五类覆盖齐全、entry→success 出口可达、全部屏状态可达、HTML↔manifest 双向同步、无外部资源引用。
2. **浏览器级验证**（静态查不了的点击行为）：`python skills/ui-prototype-gen/scripts/verify_prototype.py 08-prototype.html`——本机装有 Playwright 时逐条 manifest 路由真实点击，核对手机切屏/切态与可见反馈；无 Playwright 时脚本输出手工验证清单，逐项执行并把结果记入 `08-findings.md`（或交付说明）：
   - 页面列表每个页面项点击后手机切到对应页面/状态，高亮同步移动；
   - 主流程仅用**手机内控件**从起点走到成功出口，逐段有可见状态反馈；
   - 异常/校验失败态可见（错误定位、保存禁用），修复后可保存；
   - 取消/返回路径可用，异常路径可返回；
   - 重置流程后回到确定初始状态（entry）；
   - 断网双击打开可运行（无外部请求）。
3. 🔴 清零；🟡 全处置；每维度有结论；可点原型走通主流程。

## 人工决策点

审 crit 处置（豁免是否成立）；U-x 的倾向方案确认。

## 坑（实战教训）

- 侧栏页面列表做完就收工=假交互——主流程必须由手机内真实控件触发（R8-4）；
- 手机被拉伸成桌面宽度/换成桌面页=破版——`.device-frame` 锁 tokens.canvas，gate 按 device-frame 校验锁宽锁高；
- manifest 写了但 DOM 走不到=悬空路由——gate 静态查目标存在/可达/section 同步，浏览器验证查真实点击；
- 弹层确认、Tab、输入、保存不留可见变化=断链——每个可操作控件必有可见状态反馈；
- 调试控件（重置/上一步/下一步）做成了产品交互的替代品——它们只能在外壳上，手机内主流程必须走真实控件。
