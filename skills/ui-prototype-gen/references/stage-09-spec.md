# 阶段 9：交付规格导出（任务卡）

## 目的

把全部过程产物组装成**自包含设计规格**——编码智能体（或工程师）拿它与 tokens + 高保真参照即可开工，不需要翻任何过程文件。

## 产出与模板（`09-spec.md`，十节）

1. **消费者与契约范围**：本文 + `06-tokens.json` + `07-hifi/` 为契约；其余为过程产物可作背景。
2. **设计前提**：决策台账的最终快照（表格：决策/值）——全部已拍板项，含变体选择与 P4-x 修订。
3. **IA 与导航**：Mermaid IA + 转场表（引用并入，不外链）。
4. **领域语义**：语义态三元组表（色/符号/文字）——全局唯一"带色"语义。
5. **逐屏规格**：每屏 job / 结构（自上而下区块）/ 状态×呈现 / 交互与规则挂接（R#）/ 文案要点 / 参照帧文件名 / 验收点。
6. **核心屏模式×状态矩阵**：全文嵌入（最关键的契约，不外链）。
7. **设计系统契约**：token 数据源指针 + 规则要点 + 组件样张指针。
8. **实现注意**：mock 与真渲染的边界（领域渲染器职责）、时基/性能约束、safe-area、并发回归项、待定参数（引 PRD 未决）。
9. **未决决策位 U-x**：每个给"编码按倾向实现 + 可切换"的处理。
10. **验收标准 + 产物索引**：设计层成功标准（阶段 1 定的）+ 契约/过程文件分类表。

## 完成标志

自包含性测试：只给 `09-spec.md + 06-tokens.json + 07-hifi/` 三样，另一会话的 AI 能回答"每屏长什么样、有哪些状态、点什么去哪、守什么规则"无遗漏。

## 工具化要点（网页工具映射）

- AI 任务：规格组装=一次调用（输入=台账+03+07 索引+矩阵+findings 终态）。
- **这是"导出"按钮**：工具内规格=数据库记录的投影；导出物=文件包（spec+tokens+参照帧），可直接交给下游编码智能体。
- gate：自包含性抽检（用独立会话问 N 个规格问题，答不出=缺项）。
