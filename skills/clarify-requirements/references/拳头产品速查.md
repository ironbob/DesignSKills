# 拳头产品速查 + 覆盖地图

> 配合 `clarify-requirements` skill 的领域分析（见 `domain-analysis.md` 第二节分析维度、第六节兜底机制）。
> **用途**：领域分析命中节点后，从这里快速取该品类的对标拳头产品；每个产品"做对了什么"的详细归因在对应节点文件里。
> **来源**：本目录产品均来自预置领域节点，运行时标注 `【内置·<节点>】`；**未命中节点的品类走"模型内置知识"兜底**（2-4 个头部产品，标 `【模型内置知识·未核对】`），仅冷门 / 新品类 / 事实数据才联网核实（见 `domain-analysis.md` 第六节）。
> **覆盖**：C 端 15 类 / B 端 7 类 / 开发者工具 7 类（含 3 个根节点）。

> 维护：新增 / 改动节点时同步本目录（lint 会校验每个节点路径都在此被引用，防漂移）。
