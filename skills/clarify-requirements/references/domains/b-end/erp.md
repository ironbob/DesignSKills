## 匹配信号
- 关键词：进销存 / 采购入库 / 销售出库 / 库存周转 / 供应链 / 财务总账 / 业财一体 / 成本核算 / 多组织 / BOM。
- 场景：企业要打通"采—存—产—销—财"全链路，做到账实相符、单据可追溯、成本可核算。

## 继承要点（速览）
B 端通用全适用；ERP 的增量是——**业财一体 + 单据链贯通 + 多组织主数据**（一张采购单要自动驱动库存、应付、成本、总账，跨组织跨币种）。

## 核心价值要素
让企业的**物料、资金、账务**三流合一、实时一致、可追溯。不可缺：① 业财一体（业务单据自动生成凭证，账实相符）② 单据链贯通（订单→出入库→结算→凭证，可正反向追溯）。

## 业界标配功能
- 主数据治理：物料/客户/供应商/组织/币种统一编码，防重防错（主数据乱则全系统乱）。
- 采购到付款（P2P）：请购→采购订单→收货入库→发票校验→应付→付款，单据链贯通。
- 订单到收款（O2C）：销售订单→发货出库→开票→应收→收款，账期与信用额度控制。
- 库存与仓储：实时库存、多仓/多货主、批次/序列号/效期管理、安全库存预警、盘点与盘盈盘亏。
- 成本核算：标准成本/实际成本、BOM 展开、制造费用分摊、差异分析。
- 财务总账与多账簿：多组织/多准则（中国会计准则 vs IFRS）多账簿并行，自动结转。
- 单据状态机与审批：单据流转、红冲/驳回、预算控制（超预算自动拦截）。
- 报表与对账：资产负债/利润/现金流量表，业财差异对账（库存账 vs 实物、应收 vs 客户对账单）。
- 审计与权限：操作留痕、功能/数据/字段级权限、会计期间锁定（关账后不可改）。

## 业界标杆做法
- **SAP（S/4HANA）**：全球化 ERP 龙头 —— 以"行业最佳实践 + FI/CO/MM/SD/PP 模块化 + 多准则多币种"支撑跨国集团，验证了"主数据统一 + 单据链贯通"是 ERP 可扩展的地基。
- **Oracle（Fusion Cloud ERP）**：以数据库底座见长 —— 用"数据模型 + GenAI"做业财分析与预测，在大型跨国与互联网企业落地，把"业财数据一模型"做到极致。
- **用友（BIP / NC Cloud）**：国产大型 ERP 代表 —— 在"集团化多组织财务管控 + 国央企国产化替代"占主导，本地化中国会计准则与监管报送最贴合。
- **金蝶（星瀚/苍穹 / 云·星空）**：云原生 + 业财一体先行者 —— 以"星空货钱账票一体化 + PaaS 苍穹"覆盖大中小微，验证了微服务架构能让进销存随业务快速扩展。
- **鼎捷（易飞/ERP）**：制造业 ERP 标杆 —— 以"按行业预置 + 3 个月可上线"解决制造企业 MES/生产协同痛点，证明"行业模板"比"通用功能堆叠"更省实施成本。

## 常见陷阱与反模式
- 业务与财务两套账 → 业财不一体，月底对不上账（ERP 退化为"高级进销存"的头号症状）。
- 主数据各搞各的 → 物料/客户重复编码，跨模块统计失真，越用越乱。
- 单据链断点 → 订单与出入库、出入库与凭证对不上，无法正反向追溯，盘点永远有差异。
- 上线求大而全 → 一期就想覆盖所有模块，实施周期拉长到 1-2 年，业务等不起而流失信任。
- 关账无控制 → 会计期间不锁定，已结账数据被随意改动，审计与合规失败。
- 只重功能不重数据质量 → 系统很全但数据脏，报表没人信，最终回退到 Excel。

## 本节点专属澄清
- 覆盖范围：只要**进销存**，还是要**业财一体**，还是含**生产/MES/成本核算**？（决定模块边界与实施量级）
- **多组织/多账簿**需求（几个法人、是否多准则/多币种）？
- 主数据现状：物料/客户/供应商是否已有统一编码？由谁治理？
- **单据链**要贯通到哪一步（订单→出入库→发票→凭证→总账全通 还是只到出入库）？
- 与 **WMS/TMS/MES/CRM/电子发票/银企直联** 的对接边界？
- 合规硬要求：中国会计准则？国央企国产化信创？税务/审计报送？
- 实施节奏：一期最小可用范围 + 上线 SLA（账实相符率、月结天数）？
