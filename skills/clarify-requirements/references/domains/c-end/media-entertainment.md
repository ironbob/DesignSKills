## 继承要点（速览）
C 端低摩擦与心流适用；媒体娱乐的增量是——**版权内容供给 + 个性化推荐 + 续费会员变现**，内容版权是护城河也是成本中心。

## 核心价值要素
让用户**轻松找到想看 / 想听的内容、流畅消费、愿意续费**。不可缺：① **内容供给与版权**（没有版权库就没有内容）② **找得到**（搜索 + 推荐 + 分类，海量内容里定位）③ **流畅播放**（卡顿 / 音质画质差直接劝退）。

## 业界标配功能
- **播放器**（音视频 / 阅读：播放进度 / 倍速 / 音质画质 / 字幕 / 离线缓存 / 后台播放 / 续播）。
- **内容组织**：音乐歌单 / 专辑、影视剧集 / 综艺、书架 / 书单、播客订阅、分类 / 频道。
- **搜索 + 推荐 + 排行榜**（每日推荐 / 个性电台 / 猜你喜欢 / 热榜）。
- **会员 / 付费**（VIP 解锁 / 去广告 / 高音质画质 / 抢先看，连续包月 / 自动续费）。
- **互动**：弹幕 / 评论 / 点赞 / 收藏 / 分享（影视 / 音乐强需求）。
- **个人库**：我的收藏 / 历史 / 下载 / 关注。
- 消息（更新提醒 / 关注更新 / 活动）。

## 业界标杆做法
- **网易云音乐 / QQ音乐**：歌单 + 每日推荐 + 评论区社区，把"听歌 + 找共鸣"做成留存，版权是竞争核心。
- **Spotify**：个性化推荐（Discover Weekly）/ Daily Mix + 播客，算法推荐是招牌护城河。
- **爱奇艺 / 腾讯视频 / 优酷**：影视综艺版权 + 自制剧 + 会员抢先看 + 弹幕，追剧付费标杆。
- **微信读书 / Kindle**：电子书 + 划线笔记 + 书架同步，把"阅读 + 标注 + 跨端"做成体验。
- **喜马拉雅 / 播客平台**：有声书 / 播客 + 订阅 + 离线，把通勤 / 碎片场景的耳朵时间占领。
- **B 站**：中长视频 + 弹幕文化 + 追番，PUGC 与社区认同的标杆。

## 常见陷阱与反模式
- 版权不全 / 内容下架 → 用户找不到想看想听的，直接流失到竞品（媒体类头号死因）。
- **广告过长 / 强制广告** → 消费体验被反复打断，劝退且差评。
- 推荐不准 → 海量内容里找不到感兴趣的，停留与留存塌方。
- 播放卡顿 / 音画质差 → 核心体验崩坏，一次性弃用。
- **续费 / 退订陷阱**（自动续费难取消）→ 监管红线 + 口碑反噬。
- 阅读类无笔记 / 无同步 → 跨端 / 复盘断裂，深度用户流失。

## 本节点专属澄清
- 偏**音乐**、**长短视频 / 影视**、**播客 / 有声**还是**电子书阅读**？播放器与内容模型差异大。
- **版权 / 内容供给**从哪来（自购版权 / 自制 / UGC / 聚合）？版权缺口怎么补？
- 核心变现是**会员付费**、**广告**还是**单片购买**？广告与体验怎么平衡？
- 推荐主要靠**算法**、**编辑精选**还是**社交 / 排行**？
- 离线 / 缓存 / 后台播放 / 跨端续播要不要支持？
- 续费 / 退订流程是否清晰合规（自动续费提示、退订入口）？
