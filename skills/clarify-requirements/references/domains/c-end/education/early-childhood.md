# 早教 / 启蒙（0-6 岁） 领域知识

> 树路径：c-end > education > early-childhood
> 继承：`c-end`、`c-end/education`（学练测评闭环 / 激励 / 低摩擦仍适用）
> 使用前先读父类：[`README.md`](README.md)（教育）、[`../README.md`](../README.md)（C 端）

## 匹配信号
- 关键词：早教 / 启蒙 / 幼儿 / 0-6 岁 / 学龄前 / 识字 / 拼音 / 启蒙英语 / 思维 / 绘本 / 儿歌 / 动画 / 亲子 / 在家早教。
- 场景：家长带 3 岁孩子看动画学英语、睡前亲子共读绘本、用平板做思维启蒙闯关。

## 继承要点（速览）
教育的学练测评闭环与激励适用（需"游戏化"包装）；早教的增量是——**家长是决策者与付费方、孩子是使用者**的双角色，以及**年龄分龄 + 亲子互动 + 幼儿合规**。

## 核心价值要素
让 0-6 岁孩子**在玩中学、家长放心且愿意付费**。不可缺：① **分龄内容**（0-3 / 3-6 认知与操作能力差异巨大，一刀切用不了）② **游戏化 / 动画化**（幼儿坐不住，必须用玩吸引）③ **家长角色**（家长决定买不买、看效果、控时长）。

## 业界标配功能
- **分龄体系**（按月龄 / 岁段切分内容，0-3 / 3-6 差异显著）。
- **动画 / 游戏 / 互动绘本**形式（视频 / 拖拽 / 点读 / 跟读，玩中学）。
- **分科启蒙**：语言（识字 / 拼音 / 英语）、思维（数学 / 逻辑）、艺术（音乐 / 美术）、通识。
- **互动反馈**：答对鼓励、答错不打击、跟读评分（幼儿要强正反馈）。
- **家长端**：学习报告 / 时长管控 / 内容选择 / 续费（决策与付费方）。
- **进度与激励**：关卡 / 星星 / 奖励贴纸 / 成就（轻量、视觉化）。
- **护眼 / 防沉迷**：单次时长、休息提醒、家长锁（幼儿健康与合规红线）。
- 离线缓存 / 投屏（家庭场景常用）。

## 业界标杆做法
- **斑马（原斑马AI课）**：AI 互动课 + 动画 + 辅导老师，把学科启蒙做成"动画 + 互动 + 伴学"体系课，分龄分科。
- **小步在家早教（小步亲子）**：家庭早教课程 + 亲子互动方案，强调家长参与和科学育儿，0-6 岁分龄。
- **宝宝巴士（BabyBus）**：儿歌 / 动画 / 互动游戏海量免费内容，靠 IP（奇奇妙妙）和内容矩阵占住幼儿注意力。
- **常青藤爸爸**：双语启蒙（英语 / 古诗词）+ 音乐 + 绘本，主打内容品质与双语体系。
- **Khan Academy Kids**：免费全科启蒙 + 互动绘本 + 适配幼儿的奖励机制，把"公益 + 高质量"做到标杆。
- **叽里呱啦**：幼儿英语启蒙 + AI 互动 + 分级体系，英语启蒙垂类标杆。

## 常见陷阱与反模式
- 内容**不分龄**（0-3 给 5 岁内容）→ 孩子不会操作 / 看不懂，直接弃用（早教头号死因）。
- 做成"枯燥学习"而非**玩中学** → 幼儿坐不住，留存崩盘（幼儿留存全靠趣味）。
- **忽视家长角色** → 家长看不到效果、控不了时长，付费与续费断（家长是付费方）。
- **无护眼 / 无时长管控** → 健康与合规红线，家长口碑反噬。
- 互动反馈过于严苛（答错就扣分 / 挫败）→ 伤幼儿自信与兴趣。
- 内容质量 / 价值观问题 → 家长极其敏感，一次翻车口碑崩坏。

## 本节点专属澄清
- 目标**年龄段**是几岁到几岁？（0-3 与 3-6 的内容与交互完全不同）
- 启蒙**科目**是哪些（英语 / 识字 / 思维 / 艺术 / 通识）？
- 形态是**动画 / 互动游戏 / 绘本 / AI 课**哪类？是否需要辅导老师 / 伴学？
- **家长端**要看什么（学习报告 / 效果）、管什么（时长 / 内容）、是不是付费决策方？
- 是否需要**亲子互动 / 共学**（而非孩子独自用）？
- 护眼 / 时长管控 / 防沉迷做到什么程度（合规与口碑）？
- 变更内容是否经过**分龄教育专业性**打磨（避免"伪早教"）？
