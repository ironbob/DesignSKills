# 游戏 领域知识

> 树路径：c-end > games
> 继承：`c-end`（低摩擦 / 心流 / 留存 / 激励仍适用）
> 使用前先读父类：[`README.md`](README.md)

## 匹配信号
- 关键词：游戏 / 玩 / 关卡 / 闯关 / 对战 / PVP / 排位 / 战斗 / 角色 / 装备 / 技能 / 抽卡 / 氪金 / 充值 / 礼包 / 公会 / 副本 / 签到 / 体力。
- 场景：等车玩两把消除、晚上和朋友组队开黑、抽卡养成角色、打排位上分。

## 继承要点（速览）
C 端低摩擦与心流全适用；游戏的增量是——**核心玩法循环（core loop）+ 数值 / 经济系统 + 留存与付费设计**，是"心流 + 激励"做得最重的品类。

## 核心价值要素
让玩家**玩得爽、想再来、愿意付费**。不可缺：① **核心玩法循环**（动作 → 奖励 → 成长 → 再动作，断了就不好玩）② **难度心流**（挑战与能力匹配，太简单无聊、太难放弃）③ **成长与目标**（等级 / 装备 / 收集 / 排名，给玩家明天再来的理由）。

## 业界标配功能
- **核心玩法**：休闲（消除 / 合成 / 跑酷）、中重度（MOBA / FPS / RPG 对战 / 副本）、SLG（建城 / 兵种 / 联盟战争）。
- **关卡 / 匹配 / 对战系统**（关卡推进、PVP 匹配、排位赛段位）。
- **成长系统**：角色 / 装备 / 技能 / 等级 / 天赋，升级与养成。
- **抽卡 / 开箱 / 商城**（角色 / 道具获取与付费，概率公示是合规要求）。
- **经济系统**：体力 / 金币 / 钻石 / 付费货币，产出与消耗平衡。
- **留存激励**：签到 / 每日任务 / 连续登录 / 成就 / 公会。
- **社交**：好友 / 组队 / 公会 / 师徒 / 排行榜（中重度与 SLG 强需求）。
- **新手引导 / 教程**（前几分钟留不住就永久流失）。
- **数值与防沉迷**（未成年人保护、时长与充值限制——合规红线）。

## 业界标杆做法
- **开心消消乐 / Candy Crush / 羊了个羊**：休闲三消 + 关卡递进 + 体力限制 + 难度心流，把"再来一关"做成留存引擎。
- **王者荣耀 / 英雄联盟手游**：MOBA 公平对战 + 段位排位 + 社交开黑，把"组队上分"做成社交钩子。
- **原神**：开放世界 + 角色养成 + 抽卡 + 内容更新，用高质量内容与角色驱动付费与长线留存。
- **和平精英 / PUBG Mobile**：战术竞技（吃鸡）+ 匹配 + 赛季通行证（Battle Pass），通行证是付费与活跃的标杆机制。
- **三国志·战略版 / 率土之滨**：SLG 联盟战争 + 领地 + 长线赛季，社交与集体目标驱动留存与重氪。
- **Royal Match**：消除 + 元游戏（装修 / 剧情）融合，弱化失败惩罚提升留存，是近年休闲变现标杆。

## 常见陷阱与反模式
- **核心玩法不好玩 / 循环断裂** → 一切留存与付费都无从谈起（游戏头号死因）。
- 难度曲线失衡（前期太难劝退 / 后期太简单无聊）→ 心流断裂，两端流失。
- 数值 / 经济崩坏（产出泛滥或付费碾压）→ 免费玩家流失、生态空心化（免费玩家是付费玩家的内容）。
- **氪金过深 / pay-to-win** → 口碑反噬、监管风险，逼退零氪 / 微氪大盘。
- 新手引导差 → 前几分钟流失（游戏类最关键的留存窗口）。
- **未成年人防沉迷 / 充值限制缺失** → 监管红线，下架风险。
- 内容更新断档（中重度 / SLG）→ 老玩家长草流失。

## 本节点专属澄清
- 是**休闲**、**中重度（MOBA / FPS / RPG）**还是**SLG**？品类不同，玩法 / 数值 / 社交模型差异巨大。
- **核心玩法循环**是什么（一句话讲清"玩家反复在做什么、得到什么"）？
- 留存靠**关卡推进**、**对战排位**、**角色养成**还是**联盟 / 社交**？
- 变现模型是**广告**、**内购（抽卡 / 礼包）**还是**通行证 / 订阅**？数值怎么平衡不伤公平？
- **经济与数值系统**（体力 / 货币 / 产出消耗）怎么设计，避免崩坏？
- 未成年人**防沉迷与充值限制**（实名 / 时段 / 金额）合规怎么落地？
- 新手前几分钟的**引导与心流**怎么设计，保住首日留存？
