- 场景：花完钱顺手记一笔、月底看钱花在哪、买基金看持仓收益、扫码付款收款。

## 继承要点（速览）
C 端低摩擦与留存适用；金融的增量是——**数据准确性、资金安全、合规**三道红线，以及**信任优先于体验**。

## 核心价值要素
让用户**管清自己的钱、安全地收付、理性地理财**。不可缺：① **账目 / 资金准确无误**（算错一分钱信任归零）② **资金与隐私安全**（支付 / 身份 / 持仓数据是底线）③ **低摩擦录入或收付**（记账 / 支付的最大流失点都在"麻烦"）。

## 业界标配功能
- **记账类**：快速记一笔（金额 / 分类 / 账户 / 时间）、多账户（现金 / 银行卡 / 信用）、收支分类、周期报表（日 / 周 / 月）、预算与超支提醒、账单导入 / 周期账单、数据导出与备份。
- **支付 / 钱包类**：余额 / 收付款码 / 扫码、转账 / 红包、账单与交易明细、银行卡绑定、实名认证、安全锁 / 指纹 / 刷脸。
- **理财 / 投资类**：行情与持仓、收益 / 盈亏、申购赎回下单、自选 / 关注、资讯 / 研报、风险测评、合规风险提示。
- **信用类**：信用分 / 额度、还款、分期、账单。
- 统一的安全（支付密码 / 生物识别 / 设备管理 / 风控）与合规（实名 / 反洗钱 / 投资者适当性）。

## 业界标杆做法
- **随手记 / 挖财**：把"3 秒记一笔"当核心指标，账单导入 + 多账户 + 报表，是国内个人记账老牌。
- **MoneyWiz**：多账户 + 预算 + 自动规则 + 跨端同步，把记账做成专业级财务管理。
- **支付宝 / 微信支付**：扫码收付 + 账单 + 余额宝 + 信用（芝麻 / 微信支付分），把支付做成生活基础设施。
- **招商银行 App / 各银行 App**：账户 + 转账 + 账单明细 + 理财，银行系安全与合规的标杆。
- **雪球 / 富途 / Robinhood**：行情 + 持仓 + 社区 / 讨论 + 下单，把投资做成"看盘 + 交流 + 交易"一体。
- **钱迹**：主打"无广告、无理财推销、纯记账"，用极简和克制切中反感推销的用户。

## 常见陷阱与反模式
- 记账录入流程太长 → 用户坚持不下来（记账类头号流失原因，业界公认 3 秒是阈值）。
- 在记账 / 钱包里硬塞**理财推销** → 消耗信任，用户弃用（理财类是合规与口碑双高压区）。
- 账目 / 收益算错或同步延迟 → 一次出错信任归零，金融口碑是单点毁全局。
- 支付 / 实名安全做弱 → 资金风险 + 监管红线，出事即下架。
- 分类 / 账户层级过细 → 维护成本高，用户放弃记账。
- 投资类**缺风险提示 / 适当性** → 合规违规 + 用户亏损纠纷。

## 本节点专属澄清
- 偏**记账**、**支付 / 钱包**、**理财 / 投资**还是**信用**哪一类？子品类差异极大，先定边界。
- 录入（记账）或收付（支付）要做到多快、几步内完成？
- **资金与数据安全**（支付密码 / 实名 / 风控）做到什么级别？
- 合规要求（实名认证 / 反洗钱 / 投资者适当性 / 风险提示）覆盖哪些？
- 理财 / 投资内容是**自营**还是**代销 / 接入**？风险与适当性怎么管？
- 是否需要**账单导入 / 多账户同步**？数据导出与备份是否提供？
