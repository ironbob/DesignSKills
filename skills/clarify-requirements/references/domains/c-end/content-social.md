# 内容 / 社交 / 社区 领域知识

> 树路径：c-end > content-social
> 继承：`c-end`（低摩擦 / 留存 / 心流仍适用）
> 使用前先读父类：[`README.md`](README.md)

## 匹配信号
- 关键词：短视频 / 视频 / 信息流 / 推荐 / 点赞 / 评论 / 转发 / 关注 / 私信 / 动态 / 笔记 / 话题 / 社区 / 内容创作 / UGC。
- 场景：通勤刷信息流杀时间、在社区发帖求推荐、看朋友的动态、私信聊天。

## 继承要点（速览）
C 端低摩擦与留存全适用；内容社交的增量是——**"内容供给—分发—互动—再创作"的增长飞轮**，留存靠内容而非任务。

## 核心价值要素
给用户**持续想看 / 想互动 / 想表达的内容与人**。不可缺：① **内容供给与分发**（有人产、有人看、看得准——推荐 / 关注 / 社交关系）② **低门槛互动与表达**（点赞评论是反馈信号、发帖发视频是供给入口）。

## 业界标配功能
- **信息流 / 推荐流**——内容消费的主场，停留时长与留存的核心。
- 关注 / 粉丝关系与**个人主页**（动态 / 作品 / 收藏 / 简介）。
- 互动：点赞 / 评论 / 转发 / 收藏 / 不感兴趣——推荐算法的反馈信号。
- **内容创作工具**（拍摄 / 剪辑 / 滤镜 / 模板 / 图文编辑 / 话题标签）——UGC 供给的命脉。
- **搜索 + 话题 / 标签**（找内容、找同好）。
- 私信 / 即时聊天 / 群。
- 消息中心（互动通知 / 关注更新 / 系统通知）。
- 内容治理（举报 / 屏蔽 / 审核 / 敏感词）——合规与社区氛围底线。

## 业界标杆做法
- **抖音**：全屏单列 + 强推荐算法 + 完播率导向，把"刷得停不下来"做到极致。
- **小红书**：图文笔记 + 强搜索 + 种草社区，"搜生活经验"的第二搜索引擎，UGC 质量与信任度高。
- **微信（朋友圈 / 视频号 / 公众号）**：熟人社交基本盘 + 内容分发，把私域信任嫁接到内容。
- **B 站**：PUGC 中长视频 + 弹幕 + 强社区认同，"一键三连"把互动做成文化符号。
- **微博**：公共话题 / 热搜 + 明星大 V，公共广场式分发。
- **Reddit**：兴趣版块（subreddit）+ 投票排序，靠版规与投票自治维持社区质量。

## 常见陷阱与反模式
- 推荐不准 / 内容同质 → 信息流刷不动，留存塌方（内容类头号死因）。
- 创作门槛过高 → 供给枯竭，平台变纯消费场，飞轮停转。
- **冷启动无内容** → 新用户刷到空 / 低质，首日流失。
- 互动机制缺失 → 无反馈信号，推荐学不到、创作者无激励，供给萎缩。
- 内容审核缺位 → 违规 / 引战 / 低俗泛滥，政策风险 + 社区氛围崩坏。
- 社交关系链混乱（陌生人 / 熟人混在一起）→ 用户不敢发内容，活跃度下降。

## 本节点专属澄清
- 偏**内容消费**（刷视频 / 看笔记）还是**社交表达**（发动态 / 聊天）？重心决定产品骨架。
- 内容是**平台 / UGC 供给**还是**搬运 / PGC**？供给从哪来、质量怎么控？
- 分发主要靠**推荐算法**、**关注关系**还是**话题 / 搜索**？
- 创作门槛要降到多低（模板 / 一键剪辑 / 图文）？
- 是**熟人圈**还是**陌生人 / 兴趣社区**？关系链与隐私边界怎么设？
- 内容审核与合规（未成年人保护、违规内容）做到什么程度？
