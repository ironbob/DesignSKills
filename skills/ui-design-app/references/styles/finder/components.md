# Finder 风格 · 控件规格库

> 每类控件一张状态矩阵。所有状态值引用 tokens.md；圆角/热区几何见 tokens.md §3。
> 可拷贝实现见 `assets/styles/finder/finder-ui.css`。

## 0. 单蓝规则（总纲，先于一切控件）

**系统蓝只给五处**：① 列表/导航选中（文字底）② 菜单高亮 ③ 主按钮 ④ 焦点环 ⑤ 进行中进度。

| 语义 | 表现 | 反例 |
| --- | --- | --- |
| 选中/开启（用户数据态） | 蓝实底 + 白字白图标 | — |
| **默认即开的开关**（自动换行等） | **quiet-active：`control-strong` 深灰底 + 主文字色**，不长蓝 | 蓝底常驻 = 蓝通胀 |
| **菜单/下拉打开态** | **1px 内嵌蓝描边**（`inset 0 0 0 1px selection`），不长蓝 | 打开就变蓝按钮 |
| 分段激活（视图切换） | 克制浅灰底（`capsule-seg-active`）+ 主文字色 | 高饱和蓝方块 |
| hover | 极浅灰圆角底，不与任何选中争级 | hover 变蓝 |

## 1. 状态语义总表（全控件通用）

| 状态 | 值（引 tokens） |
| --- | --- |
| 默认 | 透明底 + secondary 色图标/文字 |
| hover | `control` / `capsule-hover`（≈黑 5%/白 9%）浅灰底 + label 色 |
| 按压 | 比 hover 深一档（`capsule-press` ≈黑 9%/白 13%） |
| 激活（选中） | `selection` 蓝实底 + #fff |
| quiet-active | `control-strong` + label 色 |
| is-open（菜单打开） | 1px 内嵌 `selection` 描边（底色维持默认/hover） |
| 禁用 | 整体透明度 0.35-0.45 + `cursor: not-allowed`；**不用低对比度冒充**，配禁用原因 Tooltip |
| 焦点（键盘） | 见 §4 焦点环配方族；仅 `:focus-visible`，鼠标点击不出现 |
| 危险 | 默认不用红色常驻；进菜单或确认 Sheet，确认时红底（`is-danger`） |

过渡一律 130-150ms ease（见 tokens.md 动效）。

## 2. 控件清单

### 2.1 图标按钮三档

| 控件 | 规格 | 圆角 | 用途 |
| --- | --- | --- | --- |
| 常规图标钮 | 28×28，图标 16-18px 线性 | 5px | 工具栏、列表行尾 |
| 工具栏圆钮 | 30×30 | 6px | 工具栏主档（hex 档） |
| 编辑区图标钮 | 32×32 | 6px | 画布/编辑器（热区优先） |

状态按 §1。图标统一单色线性（stroke 1.5 / round）；同组内尺寸恒定。

### 2.2 pill 按钮（胶囊内）

28×28 起（`min-width:28; height:28; padding:0 6px`）、圆角 999、13px/500；
图标 18px（分段钮 17px）。用于工具栏胶囊内的导航/动作/分段。

### 2.3 分段控件（互斥视图切换）

托盘 `control` 底 + 2px padding + 7px 圆角；子项 28×28（胶囊内为 999 圆角）。
**激活 = 浅灰**（`capsule-seg-active`），不是蓝。带文字的分段子项高 22px/12px 字。

### 2.4 主/次按钮（Sheet 与关键动作）

| | 高 | 圆角 | 样式 |
| --- | --- | --- | --- |
| Sheet 级 | 32px，padding 0 16px，13px | 7px | 主=蓝实底（hover brightness 1.08/按压 0.92）；次=1px divider 描边 + control 底 |
| 工具栏级 | 28px，padding 0 12-14px | 6px | 同语义缩小档 |

主按钮可带内嵌 kbd 提示（10px/400/75% 透明白，如 ⌘S）。

### 2.5 输入类

| 控件 | 规格 |
| --- | --- |
| 通用输入 | `control` 底、6px 圆角、透明边；聚焦=蓝边 + 2px 25% 蓝环 |
| 带标签紧凑字段 | 高 28、`control` 底、6px 圆角；左 11px 标签/右模式角标（10px mono） |
| 搜索胶囊 | 36px 高、18px 圆角、胶囊材质（materials §3）；聚焦叠 3px 30% 蓝环；无效=3px 35% 红环 |
| 路径编辑态 | 浏览态透明（标题式），进入编辑转 10px 圆角输入材质 + 22% 蓝环 |
| 开关（macOS 式） | 34×20、10px 圆角轨；开=蓝轨白钮，关=`control` 轨；钮 16px 带 0 1px 2px 投影，`transform` 滑动 130ms |

### 2.6 徽标与提示

数字徽标：15px 高、999 圆角、蓝底白字 9px/600、1px 宿主底色描边（切开宿主背景）。
预览格式徽标：min 22px 高、5px 圆角、`control` 底、10px mono/500、ls .025em。

### 2.7 分隔与分组

- 组内竖分隔线：1×18px、`divider` 色、margin 0 4px。**间距即分组**优先于画线。
- 菜单分组分隔线：1px、左缩进与文本列对齐（34px）、右收 12px；只出现在语义组之间。

### 2.8 NSMenu 菜单行（三列解剖）

```text
│ 16px 图标 │ 8px │ 文本（弹性） │ 16px+ │ 快捷键/子菜单箭头 │ 12px │
└─ 10px 左内边距 ──────────────────────────────── 12px 右内边距 ─┘
```

行高固定 28px、整行可点；文本 14px、快捷键 12px 右对齐；无图标项保留同宽占位
（三列起点恒定）；箭头 11px 占快捷键列位；快捷键与箭头不同时出现。
高亮 = 悬停 = 键盘焦点（同一状态）：**蓝底白字**，图标 88% 白、快捷键 72% 白；
禁用行整体 35% 且永不进高亮。

### 2.9 滚动条

见 tokens.md §7。任何滚动容器统一，不自造。

## 3. 列表族

| 元素 | 规格 |
| --- | --- |
| 列头 | 25px 高、11px/500、header-label 色、`list-header` 材质底（亮 rgba(255,255,255,.92)） |
| 行 | 13px 主行字（名 500）、行圆角 6px、斑马纹偶数行 `zebra` |
| hover | `row-hover`（不与选中争级；选中行 hover 不变） |
| 选中 | **图标底**（`selection-bg` 浅灰圆角，包住图标/缩略图）+ **文字底**（`selection-text-bg` 蓝圆角白字，只包名称）；**禁止整行高亮**；元数据列不参与高亮 |
| typeahead | 命中字符叠 `mark-bg` 半透明块 |

三视图（列表/网格/分栏）**同一套**选中语言。

## 4. 焦点环配方族

| 场景 | 配方 |
| --- | --- |
| 通用输入聚焦 | border 蓝 + `0 0 0 2px selection 25%` |
| 搜索/路径胶囊聚焦 | 原阴影 + `0 0 0 3px selection 30%`（不整圈实蓝） |
| 键盘导航（:focus-visible） | `0 0 0 3px selection 45%`（标签等可叠 inset hairline） |
| 编辑区 focus-visible | `outline: 2px solid selection; offset 2px` |
| 错误 | 3px 35% 红环（聚焦时 border 红 + 环） |

只用 `:focus-visible`（鼠标点击不出现焦点环）。

## 5. 文案与图标纪律

- 图标表达对象/操作语义（文件夹/拷贝/导出），不用"眼睛"通吃预览。
- 图标钮必须有 Tooltip + 无障碍名 + 可见键盘焦点；Tooltip 说明动作而非重复图标名。
- 状态不只靠颜色：成功/失败/暂停 = 图标 + 文字。
- 中文界面用 macOS 简体术语（拷贝/剪切/显示简介/移到废纸篓/快速查看），省略号用 `…`。
