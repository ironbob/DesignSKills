# Figma 风格 · 迁移身份

> 证据边界：锁定 2025-04-30 后正式 UI3；默认是 docked/resizable panels + bottom toolbar，浮板仅限 Minimize UI 等上下文。具体数值为 derived。详见 `evidence.md`。

## 风格命题

以中性专业工具 chrome、微型控件、精确数值和选择蓝表达创作工具感；不是把任意产品变成画布编辑器。

## invariant

- UI chrome 中性克制，选中蓝承担对象/当前项选择、焦点和唯一关键操作，不作大面积装饰。
- 控件、属性值和图标保持全目录最微型但仍可读；数字信息使用等宽与 tabular 数字。
- 工具激活与普通 hover 使用中性灰，和对象选中蓝严格分开。
- 属性、图层和操作组件提供即时反馈；拖拽/数值变化不等待装饰动画。
- 停靠面板、浮层、底部工具条和画布对象各有独立层级语言，不把对象控制柄做成面板组件。

## adaptive

- 非创作工具可提高字号和热区以满足平台与可访问性，但保留同系统内最紧凑的相对关系。
- 目标没有画布时，蓝色改为列表/对象选择语义，仍与工具激活灰分离。
- 数字拖拽只在目标已有连续数值编辑时采用。

## archetype-bound

- 灰画板 + 可折叠停靠面板、图层树、属性检查器和底部工具条只适合画布/创作类产品；浮板只在 Minimize UI 等兼容上下文采用。
- 八手柄、尺寸标签、参考线和单键工具只在目标存在对象编辑时采用。
- 列表或表单产品保留原布局，只迁移微型 chrome、选择语义和精确控件语言。

## source-specific

- Figma 图层类型、V/R/T 工具集、组件紫菱形和设计/原型/检查业务标签不是通用要求。
- 不为相似度新增画布、面板、底部工具条或对象手柄。

## 未覆盖组件推导

先判断组件属于 chrome、浮层还是业务对象；组合 11-12px 信息、24-28px 控件、4-8px 控件圆角、中性状态和选择蓝。需要更大热区时允许视觉尺寸与点击热区分离。

## 还原验收权重

`color 15 / material 10 / typography 15 / geometry 15 / spacing-density 20 / component-states 20 / motion-feedback 5 / layout-motif 0`
