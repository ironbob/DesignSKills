# Figma 风格 · 布局与交互模式（v0.x 简版）

## 1. 应用骨架（浮板 + 灰画板）

```text
┌────────────────────────────────────────────────┐
│              [ 顶工具条·浮动·居中 ]              │
│ ┌──────────┐                        ┌────────┐ │
│ │ 左·图层   │      灰画板 canvas      │ 右·属性 │ │
│ │ 浮板 248  │   （元素+选中态画在      │ 浮板   │ │
│ │          │     L0 上，无面板投影）   │ 248    │ │
│ └──────────┘                        └────────┘ │
└────────────────────────────────────────────────┘
```

- 三块白色浮板互相**不接触**，间隙 8px 露出画板灰（UI3 签名）。
- 面板浮在画板之上（z-index `--z-panel`），画布内容在 L0。
- 窄屏（<768）：左右面板收起为边缘把手（ui.css 已实现断点），画板全屏。

## 2. 键盘流（模式切换，不是命令面板）

- **单键工具**：V 移动 / A 框选 / R 矩形 / O 椭圆 / P 钢笔 / T 文字——
  按键即切换模式，工具钮 .active 跟随（与 linear 的 ⌘K 命令面板范式根本不同）。
- `Alt`+拖拽 = 复制元素；`空格`+拖拽 = 平移画板；`⌘`+滚轮 = 缩放。
- `Esc` 层层退出：关菜单 → 取消选中 → 切回移动工具。
- 属性数字输入支持 ↑↓ 微调、⇧↑↓ 步进放大。

## 3. 交互节奏

- 弹层/菜单 120ms、选中框显隐 80ms；拖拽改值零延迟（指针即值）。
- 无 hover 位移/缩放；画布操作即时反馈（选中框随手柄实时变形）。

## 4. 主题

`data-theme="dark|light"` 双主题；**亮色为默认**（创作工具画板偏好）。
组件只消费 token；暗色画板比面板深（#262626 vs #2c2c2c）。

## 5. 与 linear / geist / finder 的互换决策表（避免混搭）

| 要做的东西 | figma | linear | geist / finder |
| --- | --- | --- | --- |
| 面板布局 | 浮板+灰画板，8px 缝 | 三栏贴边+边框 | 贴边侧栏 |
| 控件尺寸 | 24-28 微型、11-12px | 28、13px | 28-32、13-14px |
| 选中语义 | 蓝=**画布元素选中**（选框/手柄/尺寸标签） | 弱紫=列表选中 | 蓝实底=列表选中 |
| 工具激活 | 灰底 .active（蓝留给画布） | 紫 accent | accent |
| 键盘范式 | 单键模式切换（V/R/T） | ⌘K 命令面板 | 菜单快捷键 |
| 投影 | 面板大柔投影（身份） | 只浮层用 | 只浮层用 |
| 品牌色 | 中性 UI，蓝=选中语义 | 紫贯穿 | 各自品牌色 |

**反模式**：禁止把面板做成贴边侧栏；禁止 14px 大字正文风；禁止大面积品牌色
（Figma 彩虹只在 logo，UI 里中性 + 选中蓝）。
