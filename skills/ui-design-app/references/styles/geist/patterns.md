# Geist 风格 · 布局与交互模式（v0.x 简版）

> 侧栏、页头和部署表格是 `archetype-bound` 母题。目标产品没有对应信息时不得添加描述、CTA、
> 技术状态或部署对象；保留原结构并迁移黑白层级、细线、主操作与排版语言。

## 1. 应用骨架（侧栏 + 主区）

```text
┌──────────┬───────────────────────────────────┐
│ 侧栏      │ 页面头：标题 20px + 描述 + 右上操作钮 │
│ surface  │ 键值设置卡片（label 左 / 控件右）      │
│ 240-260  │ 部署表格（分支 mono + 状态 pill）     │
│ 导航行32 │ 用量条形图（CSS 竖条）                │
└──────────┴───────────────────────────────────┘
```

- 侧栏 = 项目切换器（switcher，-chevron）+ 导航组（图标 + 文字，选中灰底 accent 文字）
  + 底部成员头像区。
- 主区页面头是 Geist 模板：**标题 + 描述 + 右上黑主按钮**，恒定结构。
- 面板交界 1px 边框；窄屏（<768）侧栏收抽屉。

## 2. 键盘流

- `⌘K` 命令菜单是全局入口：动作 + 导航 + 搜索合一，输入即过滤，Esc 关闭。
- 列表 ↑↓ 移动、Enter 打开；输入框内快捷键全局可用。
- kbd 提示只在命令菜单/快捷键列表出现（比 linear 克制，不塞满按钮）。

## 3. 交互节奏

- 弹层 150ms（opacity + scale）；状态过渡 120ms。
- Building 状态点脉冲是唯一常驻动画；无 hover 位移/缩放。
- Toast 右下角 3s；危险操作红实底按钮二次确认。

## 4. 主题

`data-theme="dark|light"` 双主题；**亮色为默认**（Vercel dashboard 观感）。
组件只消费 token；暗色画布必须真黑 #000000。

## 5. 与 linear / finder 的互换决策表（避免混搭）

| 要做的东西 | finder | linear | geist |
| --- | --- | --- | --- |
| 主按钮 | 蓝实底 | 紫实底 | **黑白反转实底（蓝禁用）** |
| 状态标签 | 彩点+文字 | 点+文字，**禁彩底** | **淡彩底 pill + 状态点** |
| 选中 | 蓝实底反白 | 弱紫底不反白 | 灰底 + accent 文字 |
| 快捷键展示 | 藏在菜单里 | kbd chip 随处可见 | kbd 只在 ⌘K 菜单/快捷键列表 |
| 等宽点缀 | 无刻意 | 少量 | **分支/hash/ID/数值一律 mono** |
| 密度（表格行） | 30-36 | 28-32 | 36-40 |
| 侧栏宽 | ~200 | 220-240 | 240-260（带图标+描述） |
| 画布（暗） | 深灰材质 | #08090a | **真黑 #000000** |

## 6. 反模式（布局层）

1. 彩色渐变 hero/大色块、营销化排版——这是仪表盘，不是落地页。
2. 页面头缺描述或缺右上主操作钮（Geist 页头是三件套）。
3. 表格里分支名用比例字体、时间用绝对时间戳（要 mono + 相对时间）。
