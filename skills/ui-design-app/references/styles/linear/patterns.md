# Linear 风格 · 布局与交互模式（v0.x 简版）

> 三栏是 `archetype-bound` 布局母题，不是风格迁移前提。目标产品默认保留现有栏位、表格或树结构，
> 用实色分层、紧凑节奏、单紫状态和键盘反馈表达 Linear 风格。

## 1. 应用骨架（三栏）

```text
┌──┬────────────┬──────────────────────────────┐
│图│ 列表栏      │ 详情/主内容                    │
│标│ surface 底  │ canvas 底                     │
│栏│ 220-240px  │                               │
│48│ 行 28-32   │                               │
└──┴────────────┴──────────────────────────────┘
```

- 图标栏 48px（L1 surface，选中项紫底白图标 r4）→ 列表栏（L1）→ 主内容（L0）。
- 面板交界 1px 边框；无阴影。窄屏（<768）列表栏收为抽屉。

## 2. 键盘优先（风格的灵魂）

- 每个高频动作有快捷键，按钮/菜单项**展示** kbd chip。
- `⌘K` 命令面板是第二入口的总和：动作、导航、搜索合一。
- 列表 `j/k` 或 ↑↓ 移动、`Enter` 打开、`Esc` 层层退出；输入框内快捷键全局可用。
- 焦点环常显于键盘导航（:focus-visible）。

## 3. 交互节奏

- 弹层 120ms、命令面板 80ms——键盘流不允许等动画。
- 无 hover 缩放/位移；无大动效；滚动即时（无平滑滚动）。
- Toast/行内反馈短暂（2s）不打断；危险操作红底按钮二次确认。

## 4. 主题

`data-theme="dark|light"` 双主题；暗色为默认。组件只消费 token。
图标暗色不反转（单色 currentColor 自适应）。

## 5. 与 finder 的互换决策表（避免混搭）

| 要做的东西 | finder | linear |
| --- | --- | --- |
| 右键菜单 | NSMenu 蓝底白字高亮 | 灰底浮层 + 紫对勾 |
| 选中 | 蓝实底反白 | 弱紫底不反白 |
| 面板分层 | 材质模糊浮卡 | 实色 + 边框 |
| 快捷键 | 隐藏在菜单里 | kbd chip 随处可见 |
| 密度 | 30-36 行 | 28-32 行 |
