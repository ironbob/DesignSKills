# Codex 风格 · 控件规格库（v0.x）

> 实现见 `assets/styles/codex/codex-ui.css`，作用域为 `.cx-shell`。

## 1. 状态语义

| 状态 | 规格 |
| --- | --- |
| 默认 | 透明或 surface；文字为 `text` / `text-secondary` |
| hover | `cx-hover`，不位移不缩放 |
| 按压 | `cx-active` |
| 选中 | `cx-selected` 中性灰底 + 主文字；绝不反白 |
| 链接/未读 | `cx-accent`；蓝点直径 7px |
| 提交 | `cx-submit` 实底圆形按钮；仅 composer 的发送/运行操作使用 |
| 禁用 | `opacity: .42`，并保留说明或 tooltip |
| 焦点 | 2px `color-mix(in srgb, var(--cx-accent) 48%, transparent)`，仅 `:focus-visible` |

## 2. 左侧项目与会话树

- 项目名、会话名、折叠箭头均在 28–30px 行内；长名称单行省略，不换行撑高导航。
- 选中项：r8 的中性灰底；未读项单独在右侧放蓝点，不能用蓝色整行底。
- 分组标题 12px secondary；顶栏提供“新对话”、搜索和通知图标，均为 quiet icon button。
- 用户账户固定在侧栏底部，上边仅一条发丝线。

## 3. 顶栏、任务流与检查器

- 顶栏左侧：文件夹图标 + 当前任务（14px/600）+ 更多按钮；右侧只放少量窗口/面板操作。
- 主任务流宽度受控；正文可包含 Markdown、代码块、附件与短元数据，避免扩展到整个窗口。
- 右检查器：标题“环境信息”与 `+` 操作；环境项用单色线性图标，正/负数字只用绿/红文字；来源附件采用 24px 缩略图与 12px 辅助文字。
- 检查器可关闭，关闭后内容区居中列保持不变而不是被拉满。

## 4. Composer（核心控件）

- 固定在任务流底部或可视区底部，宽度跟随主内容列；白色 r16 浮卡，`min-height: 88px`。
- 顶部留给多行输入；底行左为添加附件与隐私/权限状态，右为模型下拉、语音与圆形提交。
- 附件显示为小缩略图栈，可逐项关闭；没有附件时不要保留空白附件栏。
- Enter 由产品决定是否提交；无论策略如何，`Esc` 必须先关闭最上层菜单/面板。

## 5. 项目切换菜单

- 打开来源可以是侧栏项目标题或 composer 上方项目胶囊；不要伪装成普通 `<select>`。
- 搜索框无明显外框，图标在左；项目列表行高 56px，选中行灰底、当前工作项目用右侧对勾。
- 菜单底部固定两个动作：“新建项目”与“不在项目中工作”；后者为普通文字动作，不用红色。

## 6. 反模式

1. 全屏宽的聊天气泡、角色头像瀑布或营销式 hero。
2. 将系统状态塞入主任务正文，或将上下文检查器做成永久数据表。
3. 多个彩色实底主按钮；提交按钮之外优先 quiet/outline 操作。
4. 用渐变、玻璃材质或大阴影取代留白。
5. 把蓝色选中、紫色品牌色或 Linear 的 kbd chip 语言混入此风格。
