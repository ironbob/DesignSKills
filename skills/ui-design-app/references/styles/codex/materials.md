# Codex 风格 · 表面体系（v0.x）

## 表面规则

| 层 | 表面 | 视觉职责 |
| --- | --- | --- |
| 主画布 | `canvas` 实白/近黑 | 任务、回复与阅读内容；保持最大面积干净 |
| 导航带 | `sidebar` 极浅灰/深灰 | 用轻微色差而不是厚边框建立永久导航 |
| 检查器与输入台 | `surface` + 1px `border` | 需要独立、可扫读的上下文或操作区 |
| 附件/次级条 | `surface-subtle` | 容纳附件缩略图、项目状态和辅助控件 |
| 项目菜单 | `surface` + 菜单阴影 | 短时覆盖当前任务，不使用玻璃模糊 |

## 配方

- 内容区不做卡片瀑布：任务流直接落在主画布，只有输入台、检查器与浮出菜单成为卡。
- 分区边界仅用 1px `border`；左侧栏与主内容允许这一条长期竖线，但不要再给每个组包一层卡。
- 输入台为白色圆角浮卡，附加文件显示在其上缘的浅色附件带；提交动作用单一深色圆形按钮。
- 右检查器用完整卡片轮廓与极轻阴影，分组之间用发丝线和充足留白；不要使用表格网格或多彩状态底。
- 项目切换菜单采用大圆角白面板、搜索置顶、当前项目用右侧对勾确认；“新建项目”与“退出项目”先以分隔线和项目列表断开。

## 禁止

1. 大面积渐变、毛玻璃、彩色发光。
2. 让每段长文本都落在独立卡片内。
3. 蓝色作为主按钮、整个选中行反白或为每个图标上色。
4. 过重的 1px 灰线网格；层级应先靠留白和轻色差。
