# Things 风格 · 布局与交互模式（v0.x 简版）

## 1. 应用骨架（两栏：侧栏 + 单列内容）

```text
┌──────────┬────────────────────────────────┐
│ 侧栏      │ 今天（22px 大标题）              │
│ sidebar  │ 8 月 20 日 星期四                │
│ 232px    │ ＋ 新增事项                      │
│ 行 34    │ 今晚 ──────────                 │
│ 智能列表  │ ○ todo 行（42px，宽松）          │
│ 区域色点  │ ○ …                            │
└──────────┴────────────────────────────────┘
```

- 侧栏：智能列表（收件箱/今天/即将/任何时候/某天/日志，17px 蓝图标）+ 区域（彩色圆点）。
- 内容单列、max-width ~720、大标题 + 日期副标题 + 分组头。无图标栏（linear 才有）。
- 窄屏 <768 侧栏收抽屉（ui.css 已实现 `max-width:767px` 断点）。

## 2. 键盘流（隐藏快捷键）

- 快捷键存在但**不展示**：kbd chip hover 才浮现（与 linear 的处处可见相反）。
- `⌘N` 新建 todo（聚焦顶部内联行）、`⌘F` 快捷查找、`Esc` 层层退出。
- 空格/点击切换完成态；`⌥↩` 加备注等高级快捷键放右键菜单里提示。

## 3. 交互节奏（舒缓）

- 状态过渡 150ms；勾选完成 250ms 填充+划线（标志性瞬间，勿缩短）。
- 浮层 180ms 上浮；无 hover 缩放/位移；一切尊重 prefers-reduced-motion。
- 完成不打断：无 Toast 弹跳，靠划线灰化自证。

## 4. 主题

`data-theme="dark|light"` 双主题；**亮色为默认人设**（demo 挂 light）。
组件只消费 token；图标单色 currentColor 自适应。

## 5. 与 finder / linear 的互换决策表（避免混搭）

| 要做的东西 | finder | linear | things |
| --- | --- | --- | --- |
| 右键菜单 | NSMenu 蓝底白字高亮 | 灰底 + 紫对勾 | macOS 实色灰底 hover（最素） |
| 选中 | 蓝实底反白 | 弱紫底不反白 | 弱蓝底不反白 |
| 面板分层 | 材质模糊浮卡 | 实色 + 硬边框 | 实色白净 + 柔和大投影（仅浮层） |
| 密度 | 30-36 行 | 28-32 行 | **40-44 行**（最松） |
| 快捷键 | 藏在菜单里 | kbd chip 处处可见 | hover 才浮现（克制展示） |
| 基准字号/标题 | 14 / 系统标题 | 13 / 小标题 | 14 / **22px 大标题** |
| 品牌色 | 系统蓝（跟随系统） | 单紫 | 单 Things 蓝 + 区域七色点 |

## 6. 反模式速查

禁止：紧凑密度、蓝底反白高亮、毛玻璃/半透明面板、多彩品牌色堆叠、方角复选框、
常驻 kbd chip、面板间阴影。
