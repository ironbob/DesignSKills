# 阶段 1：写作情境（任务卡）

## 目的

把写作需求读成**写作视角的理解**：谁在什么场合读、读完要相信什么/做什么。专家不马上动笔——先想清楚这三件事。本阶段不碰任何图表和正文文字。

## 输入

`00-brief.md`（写作需求，应含**硬约束**字段：格式/篇幅/必含要素/模板要求——它们直接约束阶段 3 骨架与阶段 7 字数纪律，缺字段要追问）。功课义务：能靠查证回答的先查（往届同类文档怎么写、读者单位/角色、既有结论），查不到才进问题清单，并声明"功课做了但查不到"。

## 产出与模板（写入 `01-写作情境.md`）

1. **一句话论点**：读完必须相信的那句话，格式参考「我们要做 X，因为 Y，代价是 Z」/「X 已完成 Y%，风险在 Z，请求 W」。生成 2–3 个候选论点，**按默认决策策略自动选定**（优先级：素材的成案意图 > D-x 覆盖面 > 论证弹药充足方向）；选不出强断言时选最保守候选并降置信度，同时在台账标记"交付后建议人工复核论点"。候选、选定项、理由、置信度全部记入台账。
2. **读者画像**（≤3 类，每类一行）：

| 读者 | 角色/职务 | 已知程度 | 最关心 | 最担心 | 阅读场景 |
|---|---|---|---|---|---|
| 例：技术委员会 | 架构师×3 | 熟悉现状系统 | 方案风险/维护成本 | 重写陷阱 | 会前细读 15 分钟 |

   阅读场景三分：**会前细读**（可承载密度高）/ **投屏远读**（30 秒/页，图字号与对比度要求记入张力）/ **存档查阅**（目录与检索性优先）。
3. **决策清单 D-x**：读者读完必须能回答的问题，每条标"哪类读者的问题、答错/含糊的后果"。这是后续所有阶段的覆盖基准（阶段 3 gate 用它）。
4. **写作张力**：2–5 条专家第一直觉（如"读者只有 10 分钟 → 每节必须独立成立""投屏场合 → 每屏一个论点一张图"）。
5. **问题清单**：阻塞性 A-x **仅限三种**——缺文档主题 / 缺目标读者 / 缺任何可识别素材；命中才提**一个最小阻塞问题**（附选项与推荐），等答复后继续，其余疑问一律降为非阻塞 B-x（带默认假设，记台账，交付时集中列出）。
6. **文种判定**：技术方案 / 汇报文档 / 混合（汇报带方案评审）——决定阶段 3 叙事模板；**硬约束清单**单列（必含要素映射到节的预案，如"四要素→合并进 1–5 节"）。
7. **成功标准**：≤5 条、可判定（如"评委能一句话复述论点""每个 D-x 有节回答""数字全部可溯源"）。
8. **决策台账骨架**（文件尾部，全流程追加）：

```markdown
## 写作前提（默认决策记录，后续阶段的锚）
- 文种：_自动判定（理由一句）_
- 论点：_候选 A/B/C → 选定 X（理由 + 置信度 高/中/低）_
- **阶段 N 决策（日期）**：_决策点｜候选｜选定｜理由｜置信度_
- **P-x 结构修订**：_成稿期触发的回改（回阶段 3/4）_
- **U-x 未决**：_挂需求层的歧义（交付时列出，不阻塞）_
```

## 完成标志

论点一句话成立（是断言不是主题）且已在台账记录选定与理由；每类读者画像六列齐；决策清单非空；无悬空 A-x（要么 ✅ 已答，要么本不该设为 A-x）；文种已判定。

## 默认决策策略

- **论点**：候选并排 → 按"素材成案意图 > D-x 覆盖面 > 弹药充足"选定；低置信时选保守候选并降置信度，台账标记"交付后建议人工复核论点"。
- **A-x**：仅缺主题/读者/素材三类可设 A-x，且合并为**一个**最小阻塞问题一次问出（选项+推荐）；其余疑问一律转 B-x 默认假设。
- **成功标准**：按"评委能一句话复述论点 / 每个 D-x 有节回答 / 数字全部可溯源"自动拟定，记台账。

## 坑

- 论点写成主题（"关于 X 的方案"不是论点，"X 应该做，因为 Y"才是）；
- 读者写"所有人"= 没想清楚，必须分层；
- 阅读场景不判 → 后面图表字号/密度全错。

## 工具化要点

- AI 任务：读 brief → 生成情境 memo 草稿（画像/候选论点/D-x/张力）。
- 界面：A-x 表单 + 论点候选卡片单选 + D-x 可编辑清单。
- gate：`python3 skills/expert-doc-writer/scripts/check_plan.py <ws>/ 1`——论点存在且非主题式（含"关于/介绍"判 WARN）；画像行六列齐；D-x 非空；A-x 全有下文。
