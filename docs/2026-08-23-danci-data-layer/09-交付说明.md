## 本地运行

```bash
cd doc-renderer
npm run build && npm run preview   # http://localhost:4173/danci-data-layer/
npm run dev                        # 修改预览（注意：dev 模式有 fastdom ESM 已知问题，验收走 build+preview）
```

## PDF 导出参数（重新导出时）

浏览器打印 → 存为 PDF → **开启「背景图形」**；或 Playwright：`page.pdf({ format:'A4', printBackground:true, margin:{top/bottom:'14mm', left/right:'12mm'} })`。
