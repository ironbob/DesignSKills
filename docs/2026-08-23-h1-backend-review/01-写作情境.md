## 写作张力（专家第一直觉）

1. 述职 15 分钟 → 全 deck 约 8 页，每页一个主结论，页序按演讲节奏不按文档节序。
2. 总监投屏 30 秒/页 → 标题即结论、数字直接标注在图上，口径与来源全部下沉 speaker notes。
3. TL 会现场追问 → 机制页必须展示"方案设计"细节（读写分离/事件总线），证明独立设计能力（D-2）。
4. brief 要求数据成因果链 → 每页叙事按"背景→动作→结果"组织，数字嵌在动作与结果之间，不做数字罗列。
5. 1500 字篇幅约束 → 落在 speaker notes（页面只留结论+证据），8 页 notes 合计约 1500 字。
6. 不足页是信任页不是减分页 → 主动认领 + 根因 + 已排期改进动作，与下半年规划衔接。

## 问题清单

- **阻塞性 A-x**：无（主题/读者/素材齐备，不触发暂停）。
- **非阻塞 B-x（默认假设，交付时集中列出）**：
  - B-1：『某里程碑延期一周』素材未指明具体里程碑 → 匿名化表述为"跨团队协作的一个里程碑"，不指名系统（G-2）。
  - B-2：平台与汇报人匿名 → 全文用"某跨境电商平台"、不出现姓名与内部系统代号。
  - B-3：1500 字口径落在 speaker notes（PPT 页面文字不计入，页面只留结论+证据）。
  - B-4：下半年规划目标不虚构精确数字 → 方向+可验证目标+衔接点表述；凡属计划值标 draft 档待人工复核。

## 文种判定

**汇报文档（绩效述职）**。叙事模板：SCQA 开场 → 核心结论 → 分线进展/数据 → 不足与改进 → 规划与请求。硬约束映射：

| 硬约束 | 落点 |
|---|---|
| 第一人称述职 | notes.talk 全部第一人称；页面标题保持客观结论式 |
| 两专项 + 新人培养 | 摘要页 + 专项一（结果页/机制页）+ 专项二（结果页）+ 培养页 |
| 2 个不足与反思 | 不足与改进页（risk-action） |
| ≤3 条下半年规划 | 规划与决策请求页（decision-ask） |
| 1500 字左右 | 8 页 notes.talk 合计 ≈1500 字（B-3） |
| 数据因果链 | 每页 takeaways 按 背景→动作→结果 排序 |

## 成功标准

1. 总监听完能一句话复述："他重构了订单、保住了 618，零故障零资损，还能带人，下半年想给他更大范围。"
2. 每个 D-x 有页回答（gate 校验覆盖）。
3. 每个数字可溯源 facts.json（storyboard 无裸数字，gate 强制）。
4. 两个不足各有根因与已排期改进动作，无致命项。
5. 三条规划与上半年沉淀（拆分方法论/稳定性资产/培养体系）一一衔接。
